# 서대문형무소역사관 현장체험학습 모바일 활동지 & 1~7반 교사 대시보드

기존 `학습지 허브`와 완전히 분리된 대소중학교 1학년 서대문형무소역사관 현장체험학습 전용 웹 앱입니다.

## 주요 주소 (GitHub Pages)
- **학생용 모바일 활동지·퀴즈:** `https://dallalan2277-lab.github.io/seodaemun-fieldtrip/`
- **교사용 미리보기 (정답·해설 즉시 확인):** `https://dallalan2277-lab.github.io/seodaemun-fieldtrip/?교사`
- **1~7반 공동 교사 대시보드:** `https://dallalan2277-lab.github.io/seodaemun-fieldtrip/teacher.html`
  - 특정 반 바로 열기: `teacher.html?class=1` ~ `teacher.html?class=7`
- **현장 인쇄용 QR 포스터:** `https://dallalan2277-lab.github.io/seodaemun-fieldtrip/qr.html`

## 구성 기능
1. **학생용 모바일 사이트 (`index.html`, `data.js`, `app.js`)**
   - **리플릿 탐구 단일 활동지(2번형 통합)**: 추천 관람 동선 ①~⑨ 체크 · 현장 사진 4장 확대 보기 · 1908~1998 연표 · 핵심 공간 탐구 · 인물 4명 · 역사 퀴즈 20문항
   - 1~7반 선택, 번호·이름·답안·소감 실시간 `localStorage` 자동 저장 및 `입력 초기화` 지원
   - 제출 즉시 **채점 · 정답률 · 제출 확인증 · 문항별 해설** 제공
2. **1~7반 공동 교사 대시보드 (`teacher.html`, `teacher.js`, `roster-enc.js`)**
   - 대소중학교 1학년 1~7반 **138명 실제 명렬표** 탑재 (개인정보 보호를 위해 교사 비밀번호 기반 `AES-256-GCM` 암호화 저장)
   - `전체 현황 (1~7반)` 및 `1반`~`7반` 개별 탭에서 **제출자·미제출자 확인**, `미제출자만 보기` 필터, **미제출자 명단 복사**
   - 잘못 제출·테스트 제출 건을 바로 지울 수 있는 **제출 삭제** 기능 (로컬 미리보기 & 구글 시트 양쪽 지원)
   - 기본 **정답률 높은 순** 정렬, **표 보기 / 소감문 모아보기** 전환, **반별 소감문 CSV·인쇄용 HTML 다운로드**
   - **반별 10명 문화상품권 선정**: 직접 체크 + **조건부 / 동점자 랜덤 추첨**(미제출자 자동 제외) + 반별 독립 서버 저장
3. **독립 구글 시트 백엔드 (`apps-script/Code.gs`)**
   - 자세한 연동 방법은 [설치방법.md](설치방법.md)를 참고하세요.
